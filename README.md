# IMAGINE Group AI™ — Investor Pitch Deck

A self-contained, modern slide presentation recreating the 12-slide IMAGINE Group AI investor pitch. Built as a single HTML file — no build step, no dependencies, works offline.

## Open it

Just open `index.html` in any browser (Chrome/Edge/Safari/Firefox).

1. **Title** — IMAGINE Group AI™ · The Operating System for the AI Economy
2. **One Ecosystem. Five Engines.** — Learn / Build / Create / Scale / Impact
3. **Why This Model Wins** — Traditional model vs. compounding integration
4. **Learn + Build** — Hart Academy AI™ ($28M) + Imagine AI Labs™
5. **Create + Scale** — Imagine Studios™ + Creative Intelligence™ ($42M)
6. **Impact Engine** — Economic & social impact · JohnReinhard.org™

## Export to PDF (for emailing investors)

1. Open `index.html` in Chrome
2. Press `F` for fullscreen on each slide, **or** use Print (`Ctrl/Cmd+P`)
3. For clean one-slide-per-page output, set Print → Layout **Landscape**, Margins **None**, enable **Background graphics**

> Tip: The charts (donut + revenue line) are real SVG, so they stay crisp at any size and in PDF export.

## Editing

All content, colors, and copy live inline in `index.html`. The brand palette is defined as CSS variables at the top (`:root`) — gold accents plus per-engine colors (Learn=blue, Build=green, Create=purple, Scale=orange, Impact=teal).
